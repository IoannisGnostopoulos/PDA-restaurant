# 🍽️ Restaurant Management System (Σύστημα Διαχείρισης Εστιατορίου)

Ένα ολοκληρωμένο, ασφαλές και σύγχρονο web σύστημα διαχείρισης εστιατορίου, βασισμένο σε PHP και MySQL, με προηγμένο έλεγχο πρόσβασης βάσει ρόλων (Role-Based Access Control - RBAC).

---

## 👥 Ρόλοι & Δικαιώματα Χρηστών

Το σύστημα υποστηρίζει τέσσερις (4) διακριτούς ρόλους χρηστών με αυστηρά όρια ασφαλείας:

* **1. Owner / Διαχειριστής (Role ID: 1):** Πλήρης πρόσβαση σε όλες τις λειτουργίες, συμπεριλαμβανομένης της διαχείρισης χρηστών (εισαγωγή, τροποποίηση, διαγραφή), διαμόρφωσης μενού/κατηγοριών, επισκόπησης εσόδων και εποπτείας όλων των οθονών.
* **2. Σερβιτόρος (Role ID: 2):** Πρόσβαση στο πάνελ σερβιτόρου για καταχώρηση νέων παραγγελιών και διαχείριση/κλείσιμο τραπεζιών.
* **3. Κουζίνα / KDS (Role ID: 3):** Αποκλειστική οθόνη κουζίνας για την παρακολούθηση ενεργών παραγγελιών σε πραγματικό χρόνο και ενημέρωση κατάστασης (Σε προετοιμασία / Ολοκληρωμένη).
* **4. Μάρκα (Role ID: 4):** Προβολή προϊόντων και διαχείρισης ανά κατηγορία.

---

## 🚀 Κύρια Χαρακτηριστικά

* **Ασφαλής Αυθεντικοποίηση:** Διαχείριση συνεδριών (Sessions) και προστασία διαδρομών (Route Security) ανάλογα με τον ρόλο του χρήστη.
* **Σύγχρονο UI/UX:** Σχεδίαση βασισμένη σε κάρτες (Card-based interface), ομαλά εφέ αλληλεπίδρασης (hover effects) και διανυσματικά εικονίδια SVG.
* **Διαχείριση Βάσης Δεδομένων:** Ασφαλή ερωτήματα (Prepared Statements) και δυναμική σύνδεση με MySQL.
* **Αυτόματη Ανανέωση (Auto-refresh):** Ενημέρωση οθόνης κουζίνας ανά τακτά χρονικά διαστήματα για απρόσκοπτη ροή εργασίας.

---

## 🛠️ Τεχνολογίες

* **Backend:** PHP (Session Management, MySQLi / PDO)
* **Frontend:** HTML5, CSS3 (Flexbox, Responsive Design), JavaScript (AJAX)
* **Database:** MySQL (Βάση δεδομένων `tes1`)
* **Server:** Apache (XAMPP / Localhost)

---

## ⚙️ Οδηγίες Εγκατάστασης

1. Κλωνοποιήστε το αποθετήριο ή τοποθετήστε τα αρχεία στον φάκελο του τοπικού σας διακομιστή (π.χ. `htdocs/yourfolder`).
2. Δημιουργήστε μια βάση δεδομένων με το όνομα **`tes1`** στη MySQL.
3. Εισάγετε τα απαραίτητα δεδομένα (πίνακες `users`, `orders`, `timokatalogos`, `categories_products` κ.λπ.).
4. Ανοίξτε τον περιηγητή σας και μεταβείτε στη διεύθυνση:
   `http://localhost/yourfolder/index.php`
